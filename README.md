# Atliq Hotels Data Analysis
Exploratory Data Analysis (EDA) on hotel booking data to uncover insights on occupancy, revenue, and booking behavior.

## 📊 Project Overview
- 134K+ hotel booking records analyzed
- Data Cleaning & Outlier Detection
- Occupancy Rate Feature Engineering
- Revenue & Booking Insights

## 🧠 Objectives
- Understand occupancy trends
- Evaluate revenue performance
- Identify data quality issues
- Analyze booking behavior

## 🛠️ Tools Used
Python • Pandas • NumPy • Matplotlib • Jupyter Notebook
